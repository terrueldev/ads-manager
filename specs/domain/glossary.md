# Domain Glossary

Canonical terminology for ads-manager.

## Terms

| Term | Definition |
|------|------------|
| Connected Account | A Google Ads account the user has authorized ads-manager to access via OAuth. Stores metadata (name, Customer ID, currency, timezone), an encrypted refresh token, and a status (`active`, `suspended`, `needs_reconnect`). |
| MCC (Manager Account) | A Google Ads manager account that grants administrative access to multiple sub-accounts (customer accounts). When a user authorizes via an MCC identity, ads-manager lists every accessible sub-account for selection. |
| Customer ID | The unique identifier of a Google Ads account, in the format `XXX-XXX-XXXX`. |
| Suggestion | An improvement recommendation generated by Claude from campaign performance data, with its own lifecycle (`pending` → `approved`/`rejected` → `applied`/`failed`). Introduced by the `google-ads-manager` epic; implemented starting with the `ai-performance-analysis` change. |
| google-ads-mcp-rw | The MCP (Model Context Protocol) server (github.com/maxghenis/google-ads-mcp-rw) used to apply approved suggestions as real changes to a Google Ads account. |
| ROAS | Return on Ad Spend — conversion value divided by cost. Used as a performance metric on the Campaign Performance Dashboard. |
| Micros | The monetary unit used by the Google Ads API: 1 real currency unit = 1,000,000 micros. `campaign_metrics_cache` stores cost/budget in micros; the UI converts to normal currency units for display. |

## Conventions

- Use singular nouns for definitions (User, not Users)
- Use past tense for events (UserCreated, not CreateUser)
- Be consistent with terminology across all specs
